# Contributing to The Artist Unlocked

First off, thank you for considering contributing to **The Artist Unlocked**! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## 🌈 How to Contribute

### 1. Reporting Bugs
- **Check existing issues:** Before opening a new issue, please search the tracker to see if the problem has already been reported.
- **Be descriptive:** Include your OS, version of Node.js, and steps to reproduce the bug.
- **Provide logs:** If the app crashes, include the console output from the terminal or Chrome DevTools.

### 2. Suggesting Enhancements
- Open an issue with the tag `enhancement`.
- Describe the feature you'd like to see and why it would be useful.
- If it's a UI change, a rough sketch or mockup is always appreciated.

### 3. Pull Requests
- **Fork the repo:** Create your own branch from `main`.
- **Keep it focused:** Each PR should address a single issue or feature.
- **Follow coding standards:** We use ESLint and TypeScript to maintain code quality.
- **Update documentation:** If your change affects the setup or features, please update the README.

## 🛠️ Local Development

1. Install dependencies: `npm install`
2. Run in dev mode: `npm run dev`
3. Run linting: `npm run lint`
