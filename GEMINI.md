# GEMINI.md: The Artist Unlocked - Project Context

## Project Overview
"The Artist Unlocked" is an Electron-based desktop application designed for hosting interactive music trivia quizzes. It acts as a **Quizmaster Dashboard** and a **Presentation Screen** for participants. The application leverages AI for trivia generation and Spotify for music integration.

### Core Technologies
- **Shell:** Electron (Desktop)
- **Frontend:** React 19 (TypeScript, Vite)
- **AI Integration:** Google Gemini API (`gemini-2.5-flash`)
- **Music Integration:** Spotify Web API (Search & Playback)
- **Real-time Sync:** Express, Socket.io (for Mobile Remote Control)
- **Visuals:** `tsparticles` for dynamic, genre-based background animations.
- **Styling:** CSS Modules / Vanilla CSS.

---

## Architecture & Directory Structure
- `electron/`: Main process and preload scripts.
    - `main.ts`: Handles IPC (Spotify, Config, File System), secure storage (via `safeStorage`), and the Socket.io server.
    - `preload.ts`: Bridge between main and renderer processes.
- `src/`: React source code.
    - `views/`: Main application screens:
        - `Setup.tsx`: Initial configuration (API keys, team setup).
        - `Builder.tsx`: Quiz creation and Gemini/Spotify integration.
        - `Dashboard.tsx`: Private Quizmaster control panel.
        - `Presentation.tsx`: Public-facing presentation screen with dynamic theming.
    - `services/`: API wrappers:
        - `gemini.ts`: Prompt engineering and trivia generation logic.
        - `spotify.ts`: Auth and track search logic.
    - `utils/`: Game logic (score calculation, state management).
- `public/`: Static assets and the `mobile-remote.html` used for Mode C.

## Building and Running

### Prerequisites
- Node.js (v18+)
- Google Gemini API Key
- Spotify Developer Credentials (Client ID & Secret)

### Key Commands
- `npm install`: Install dependencies.
- `npm run dev`: Start Vite and Electron in development mode (with HMR).
- `npm run build`: Compile TypeScript and build for production.
- `npm run lint`: Run ESLint checks.

### Configuration
The app stores sensitive credentials (Gemini/Spotify keys) using Electron's `safeStorage` in the user's local data directory (`config.json`). Quizzes are saved as JSON files in a `quizzes/` subfolder.

---

## Development Conventions
- **State Management:** Uses React state synced via Electron IPC/Socket.io (`broadcast-state`) to keep the Dashboard, Presentation Window, and Mobile Remote in sync.
- **Routing:** Uses `HashRouter` for compatibility with Electron's file-based loading.
- **Theming:** Visual themes (colors and animations) are generated by Gemini based on the artist's genre and applied dynamically via CSS variables and `tsparticles`.
- **API Safety:** Never hardcode API keys. Use the `Setup` view to input them, which then saves them securely.
- **Documentation Sync:** Always ensure the `README.md` is updated to reflect new features, technical changes, or updated installation steps.

## Game Mechanics to Maintain
- **Rounds:** 5 Artists per quiz.
- **The Unlock:** Identify artist via audio (Phase 1).
- **Lore Ladder:** 5 tiers of questions (10, 20, 30, 40, 50 pts).
- **All-In Token:** One-time use per team to double points.
- **Final Wager:** Secret wagers on the final question of the final artist.
